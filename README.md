E-Commerce Inventory Management System
Project Description
The E-Commerce Inventory Management System is a database project developed using SQL. It manages products, categories, suppliers, customers, orders, and inventory stock.
Objectives
Manage product information and prices.
Track available stock quantities.
Store supplier and customer details.
Maintain customer order records.
Identify products with low stock.
Calculate the total inventory value.
